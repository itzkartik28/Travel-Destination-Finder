# Travel Destination Finder 

A simple Python project that recommends suitable travel destinations based on the user's preferences.

## Features

* Select travel budget
* Choose interests and activities
* Find suitable destinations
* Simple recommendation system
* Beginner-friendly Python project

## Technologies Used

* Python

## How It Works

The program takes user preferences such as budget, interests, and preferred activities. It compares these preferences with available destination data and suggests suitable travel destinations.

## Example Destinations

* Goa
* Manali
* Jaipur
* Kerala
* Rishikesh
* Mumbai
